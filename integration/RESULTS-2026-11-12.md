## 开发中发现并修正的问题

- 初次脚本将 Android 的 `legacyNativeLibraryDir` 当作 ABI 目录，导致 SO
  `open rc=-2`；已区分正常字段和 legacy 根目录并在注入前验证文件存在。
- 首版 payload 未显式开启 Dobby near trampoline，manual 远跳转的 LDR literal
  在 overlay 下读到原始 NOP 数据，测试 App 发生 SIGBUS。已改为 near trampoline
  并验证入口 `B imm26`，最终完整轮次通过。详细原因见 [设计](../INTEGRATION.md)。
- Dobby 可选 SymbolResolver 与该 dev 源码的 RuntimeModule 定义不一致；构建关闭
  测试不使用的插件，Dobby 源码保持原样。

以上失败不被计入通过轮次。整个此次集成运行的设备 boot ID 保持
`93fd2db6-94b5-4215-a2ef-1bfb6660e360`；未热卸载/重载 KPM，未发生本轮内核重启。
设备旧的 boot reason 仍可能显示之前共存分析的 panic，不能据此判定本轮失败。
